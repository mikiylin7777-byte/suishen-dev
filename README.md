# 随身开发

[English](README.en.md) · 中文

**让不懂代码的人，也能用 AI 简单愉快地开发软件。**

随身开发不是又一个 AI，而是给你已经在用的 AI（Codex、Claude Code、T3 等任何能读写本机文件的 AI 对话）配上一套「规矩 + 记忆 + 帮手」：

- **一份公共规矩**：AI 怎么开工、怎么汇报、哪些事必须先问你（上线、改真实数据、账号密钥、花钱或对外发消息），换哪家 AI 都照同一份做。
- **项目记忆放在文件里**：每个项目的进度、功能清单、踩过的坑都写进项目自己的文件，换 AI、换电脑接着做，不靠某个 AI 的记性。
- **看板**：所有项目在哪一步、等谁、卡在哪，一页看清（可用 Obsidian 打开）。
- **合并把关**：改动的自动检查全部通过才合，分低风险、高风险两档，高风险等你点头。
- **后台**：每天自动备份、每周体检，一键升级、出问题一键退回。
- **帮手命令**：截图看成品、撤回上一个改动、把已有项目搬进来、换电脑接着做、去密钥的求助包……都由 AI 代你执行，你只用大白话说。

## 适合谁
- 想做点自己的小软件、小工具，但不会写代码的人；
- 已经在用 AI 写代码，但项目一多就乱、AI 一换就忘的人。

## 安装
**系统要求**：macOS，Python 3.9 或更新（系统自带的就行）。

1. 到 [Releases](https://github.com/mikiylin7777-byte/suishen-dev/releases) 下载最新的 `随身开发-对外版-<版本>.zip`，核对页面上的 SHA256；
2. 解压，把 `随身开发` 文件夹放到你的个人文件夹（不要放在「下载」或桌面）；
3. 双击 `开始使用.command`，按提示回答几个问题（怎么称呼你、项目放哪、代码只存本机还是也推到网上）。

装好后，在任何能读写本机文件的 AI 对话里贴一句启动语（见安装目录里的 `启动语.md`），之后用大白话说话就行，比如「各项目怎么样」「给 XX 加一个导出按钮」。

## 用起来是什么样
- 你：「各项目怎么样？」→ AI 读看板，用两三句话告诉你哪些在动、哪些等你拍板。
- 你：「给记账本加一个按月导出。」→ AI 先翻这个项目踩过的坑，补齐要求，写代码、跑测试、截图给你看；你说「可以」才合进去。
- 你：「退回上一版。」→ 随身开发回到升级前的版本。

更多见 [使用说明.md](使用说明.md)。

## 从源码运行和测试
```bash
python3 -m unittest discover -s tests      # Python 测试
(cd adapters/bots && npm ci) && node --test adapters/bots/test.mjs   # 机器人适配测试（可选）
python3 scripts/install.py /tmp/试装/随身开发  # 从源码打一份完整版到新目录
```
程序只用 Python 标准库；飞书、企业微信机器人适配用各自的官方 SDK，可选。
